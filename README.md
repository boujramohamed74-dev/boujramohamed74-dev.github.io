# تطبيق «رتب»

تطبيق لترتيب المهام والأولويات، يعمل بدون إنترنت، ويبدأ **فارغاً تماماً** عند أول تشغيل. كل مستخدم يضع مهامه بنفسه، وبياناته محفوظة على هاتفه فقط.

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | الألوان والأشكال |
| `store.js` | منطق المهام والحفظ (ومعه اختباراته) |
| `app.js` | الشاشات والأزرار |
| `sw.js` | يحفظ الملفات على الهاتف ليعمل بدون نت |
| `manifest.webmanifest` + `icon-*.png` | اسم التطبيق وأيقونته |
| `test/store.test.js` | اختبارات المنطق (`node test/store.test.js`) |

## قبل النشر: عدّل نصين

افتح `app.js` وابحث عن `CONFIG` في أعلاه، واكتب بدل النصين بين القوسين:
- `aboutText`: نص «من نحن».
- `contactText`: طريقة التواصل معك (بريد أو واتساب).

## النشر ثم تحويله إلى APK (من الهاتف)

### 1) ارفع الملفات على GitHub Pages
1. أنشئ حساباً مجانياً على github.com.
2. أنشئ مستودعاً جديداً باسم `اسمك.github.io` (استبدل «اسمك» باسم حسابك بالأحرف الإنجليزية)، واجعله **Public**. هذا الاسم يجعل رابط الموقع على الجذر، وهو ما تحتاجه الخطوة 3.
3. اضغط **Add file ← Upload files** وارفع كل الملفات بعد فك الضغط (حدّدها كلها معاً)، **ما عدا مجلد `test`** فلا حاجة له. كل الملفات في مستوى واحد، فلا توجد مجلدات تحتاج رفعها.
4. ادخل **Settings ← Pages**، واختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
5. بعد دقيقة أو دقيقتين يعمل الرابط: `https://اسمك.github.io`. افتحه في Chrome على هاتفك وتأكد أن التطبيق يعمل.

### 2) حوّله إلى APK
1. افتح **pwabuilder.com** وضع رابط موقعك واضغط Start.
2. اضغط **Package for stores** ثم اختر **Android**.
3. اضغط Generate وحمّل الملف المضغوط. بداخله ملف `.apk` للتثبيت المباشر.
4. أرسل الـAPK لمن تشاء. يسمحون بالتثبيت من مصدر غير معروف، ويفتحون التطبيق **مرة واحدة مع إنترنت** ليعمل بعدها بدونه.

> أسماء الأزرار في المواقع قد تتغير قليلاً مع الوقت، فاتبع ما يظهر لك على الشاشة.

### 3) إخفاء شريط عنوان المتصفح (اختياري)
قد يظهر شريط عنوان صغير أعلى التطبيق. تعطيك PWABuilder ملفاً باسم `assetlinks.json` ضمن الحزمة. ارفعه في المستودع داخل مجلد اسمه `.well-known` (أي `.well-known/assetlinks.json`) وأعد تثبيت التطبيق.

## تحديث التطبيق لاحقاً
1. عدّل الملفات في GitHub (زر القلم).
2. غيّر الرقم في أول سطر من `sw.js` (`rattib-v1` إلى `rattib-v2` وهكذا)، فهذا ما يجعل الهواتف تحمّل النسخة الجديدة.
3. يصل التحديث للمستخدمين تلقائياً عند فتح التطبيق مع إنترنت.

## ما الذي لا يفعله هذا الإصدار؟
- **التنبيهات** تظهر داخل التطبيق عند فتحه (شريط «تذكير» أعلى القائمة) وليست إشعارات في شريط الهاتف. الإشعارات الحقيقية تحتاج نقل التطبيق إلى Flutter أو تغليفه بـCapacitor.
- **زر الخروج** غير موجود، فأندرويد يخرج من التطبيق بزر الرجوع أو الرئيسية.
- لا يوجد نسخ احتياطي سحابي. حذف بيانات التطبيق من إعدادات الهاتف يحذف المهام.
